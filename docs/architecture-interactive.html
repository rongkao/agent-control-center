典型任務流
UI 建立 Task→ Orchestrator 分派 Claude→ Claude Adapter 產生事件→ Event Bus→ UI 即時顯示→ 需要時手動 Ask Codex→ Review / Rescue / Approval

Agent Orchestrator

點選中間任意模組檢視細節
  • 接收 UI 的高層任務，不直接處理模型細節。
  • 選擇 Claude、Codex、Both、Reviewer、Test。
  • 限制自動互審輪次與最大 Agent turn。
  • 控制 timeout、retry、cancel、approval。
  • 避免 Claude ↔ Codex 無限迴圈。
assign(task) → policy check → choose agent → start session → subscribe events → update state → decide next action

一個任務實際怎麼走

01UI 建立任務「修 bug」
02Orchestrator 指派 Claude
03Claude 事件進 Event Bus
04UI 顯示 coding / tool call
05手動 Ask Codex Review
06若 blocked → Safety / Approval
07人工批准或取消
