# Agent Control Center 使用說明

這個工具讓你在同一個畫面裡同時使用 Claude 和 Codex：直接和它們對話、讓它們互相交接、自動跑「實現 → 測試 → 修復」的流程。
所有操作都有記錄，服務重啟後也能接著做。

## 第一次使用

1. 需要 **Node.js 24 或更新版本**（到 https://nodejs.org 下載）。
2. 先各自登入一次：
   - Claude：在終端機執行 `claude`，按提示登入。
   - Codex（可選）：執行 `codex login`。
3. 在專案資料夾執行一次環境自檢：`npm run doctor`。它會用中文告訴你缺什麼。
4. 啟動：`npm run start:real`。瀏覽器會自動開啟控制台，並且已經登入。

> 如果開啟的是「需要重新登入」的頁面：用啟動時自動開啟的那個分頁，或者到終端機裡複製「訪問連結」那一行貼到瀏覽器。登入一次可以用 30 天。

## 桌面版（Windows）

- 安裝：執行 `AgentControlCenter-Setup-版本.exe`（自己建置：在專案資料夾執行 `npm run desktop:dist`，安裝程式在 `apps/desktop/release/`）。
  安裝程式沒有數位簽章，第一次執行時 Windows 可能顯示「Windows 已保護您的電腦」，按「其他資訊 → 仍要執行」。
- 第一次開啟會請你選 AI 預設工作的專案資料夾；之後可以從選單「檔案 → 更換預設工作資料夾」修改。
- 桌面版預設用真實的 Claude 和 Codex（一樣需要先在終端機登入過一次）。設定從選單「檔案 → 開啟設定檔（.env）」修改，存檔後「檔案 → 重新啟動服務」。
- 資料與命令列版共用（同一個資料目錄），原本的任務都在；兩者不能同時開啟。
- 關閉視窗時會先停下 AI、關好資料庫再結束；服務意外結束時會跳出說明，可以直接按「重新啟動」。
- 解除安裝不會刪除任務記錄。


- **新對話**：在左上方輸入你想做的事，選「對 Claude 說」、「對 Codex 說」或「同時問兩個」，按 Enter。
- **同時問兩個**：一個 AI 可以改檔案，另一個唯讀、給意見，兩個不會同時改同一份程式碼。
- **轉給對方**：每條回覆下面有「轉給 Codex / 轉給 Claude」，可以把回覆交給另一個 AI 評審或接著做。
- **換人接手**：讓另一個 AI 接手整個任務（目前的 AI 會停下）。
- **停下這一輪**：AI 做偏了時，只停它現在這一輪，任務不會結束；之後再發訊息會接回原來的對話。
- **自動流程**：展開「更多選項」勾選「自動流程」並填測試命令（例如 `npm test`）：實現 → 測試 → 失敗重試 → 另一個 AI 診斷 → 修復。
- **AI 問你問題**：AI 有時會給幾個選項請你選（或讓你自己填），在對話裡的卡片上直接回答；不想回答就按「跳過」，AI 會自己判斷。
- **AI 之間諮詢**：AI 可以「問」另一個 AI 一個問題（對方唯讀、只回答），答覆會自動交回提問的那個。

## 看改動、撤銷、分叉（工作目錄是 git 倉庫時）

任務的「改動」頁簽：

- **每一輪改了什麼**：AI 每做完一輪都會自動拍一個快照（存在 git 的隱藏位置，不會動你的分支和暫存區），可以逐輪檢視差異，也可以看「到目前為止的全部改動」。
- **撤銷最後一輪**：把檔案恢復到上一輪結束時的樣子（新增的檔案會刪掉）。可以連續撤銷，一輪一輪往前退；歷史記錄不會被刪除。
- **分叉**：在某一輪旁邊按「分叉」，從那一輪結束時的狀態開一個新任務（在新的 worktree 裡），原任務不受影響。適合「回到第 2 輪，換個做法試試」。

## 獨立 worktree 與合入

建任務時勾選「使用獨立 worktree」，AI 會在倉庫裡一個獨立的分支和資料夾裡工作，不會碰你正在用的檔案：

- 「改動」頁簽上方的「合入主倉庫」：先「預覽合入」（看會改哪些檔案、會不會衝突），再選「合入（merge，保留提交）」或「只套用改動（暫存，自己提交）」。
- 主倉庫有沒提交的改動、有衝突、或者新增內容裡像是金鑰（API key 等）時，不會合入，會用中文告訴你原因。
- 合入之後可以「刪除 worktree 和分支」。
- **多個 AI 各做一份，再選一份**：在「更多選項」勾選後，同一個要求會交給每個可用的 AI，各做一份；做完後在「改動」頁簽的「比較」裡看誰的測試通過、改得最少，系統會推薦一份，你按「選這份」合入，其餘的自動清理（花費是單份的幾倍）。

## 安全（左側「🛡 安全」）

- **自主度**：「每次都問」／「按規則」（預設）／「無人值守」（高風險以外全部自動放行）。
- **以後都允許**：審批卡片上按「以後都允許」會加一條規則（例如以後 `npm test` 都不用問），可以在這個頁面撤銷。刪除、強制推送、下載後直接執行等高風險操作永遠要你確認；連續自動放行太多次也會停下來請你確認一次。
- **執行隔離**：顯示測試和 Codex 是不是在沙箱裡跑。Windows 上要讓測試在沙箱裡跑，需要以系統管理員身分執行一次 `npx @anthropic-ai/sandbox-runtime windows-install`（會建立一個專用帳號和防火牆規則）；不裝的話測試照常執行，只是隔離比較弱。
- AI 輸出裡出現的金鑰（API key、token 等）在記錄和顯示前會自動遮掉。

## 審批

AI 要執行命令或改檔案時會先問你：

- **批准**：只這一次。**本會話都允許**：這個對話裡同類操作不再問（不會寫進任何設定檔）。
- **拒絕**：這個 AI 這一輪會停下，任務停在那裡等你決定。
- 可以點「展開完整內容」看完整的命令或檔案內容再決定。
- 開啟左側的「🔔 開啟桌面提醒」後，就算頁面在背景，需要審批時也會彈出通知；分頁標題也會顯示要處理的數量。

## 任務停下來時

頁面上的橫幅會用中文說明原因，並直接給出可以按的按鈕：

| 看到的原因 | 可以怎麼做 |
|---|---|
| 預算用完（執行時長、輪次、花費……） | 「放寬預算並繼續」 |
| AI 原地打轉（重複同一個命令或錯誤） | 補充說明後「重試」，或「換人接手」 |
| 服務重啟時有操作做到一半 | 先確認工作區的狀態，再發訊息或「重試」 |
| 另一個任務正在改同一個資料夾 | 等那邊做完，或建任務時勾選「使用獨立 worktree」 |
| 不打算再處理 | 「放棄」（歸檔，重啟後不會再恢復） |

## 整理任務

- 已經結束的任務可以「匯出記錄」（JSON Lines 檔）或「刪除任務」。
- 想自動清理：在 `.env` 裡設定 `ACC_RETENTION_DAYS=90`（結束超過 90 天的任務自動刪除；預設永久保留）。

## 設定（可選）

把專案裡的 `.env.example` 複製成 `.env` 再修改，啟動時會自動讀取。常用的有：

| 設定 | 作用 |
|---|---|
| `ACC_WORKSPACE` | AI 預設工作的資料夾 |
| `ACC_MAX_COST_USD` | 每個新任務的估算花費上限（美元） |
| `ACC_IDLE_SESSION_MS` | AI 閒置多久就釋放它的程式（預設 10 分鐘） |
| `ACC_STEP_INACTIVITY_MS` | 自動流程裡一步多久沒動靜算卡住（預設 15 分鐘） |
| `ACC_RETENTION_DAYS` | 自動刪除結束多久的任務（預設 0 = 永久保留） |
| `ACC_ACP_AGENTS` | 接入其他 AI，例如 `gemini,opencode`（需要先裝好對應的命令列工具並登入） |
| `ACC_QUESTION_TIMEOUT_MIN` | AI 的問題幾分鐘沒人回答就跳過（預設 0 = 一直等） |
| `ACC_OTLP_ENDPOINT` | 把追蹤記錄發到 Phoenix 等工具（任務詳情裡也可以「下載追蹤」） |

## 資料放在哪裡

資料庫、日誌和登入令牌都在 `%LOCALAPPDATA%\agent-control-center`（Windows），不在你的專案資料夾裡，AI 讀寫不到。
資料庫升級前會自動備份一份在同一個資料夾。

## 遇到問題

- `npm run doctor`：環境自檢。
- `npm run dump-run`：列出最近的任務和它們卡在哪裡；`npm run dump-run -- <任務 ID 前幾位>` 看某個任務的詳細記錄。
- 關閉服務：在終端機按 Ctrl+C（會先停下所有 AI、關好資料庫再退出）。
